# 最新进展与验证边界 · 2026-11-12

本次同步了视觉选择与 Lua 动作编排的运行时源码，并保留公开版的脱敏配置。它是工程源码展示，不包含可直接启动的完整 Unity 工程。

## 已实现的机制

- **可等待视觉工具**：`select_visible` 校验契约中的目标槽，等待真实定位、对准、新帧确认后才恢复 Lua。
- **独立目标授权**：契约保留原始描述来源；模型不能预填场景实体 ID，目标在确认后才绑定任务内句柄。
- **多目标账本**：任务内部选 B 保留 A；外部换选、取消及实体/任务失效另行处理。目标缺失不能借用旧 Current。
- **视角与运动衔接**：后续视觉选择读取移动/转向后的新帧，Eye 角度从当前姿态累积，身体转向与看向分开处理。
- **回执驱动的汇报**：阶段完成依据契约义务与实际工具回执，重复动作不能共用一次完成证明。

## 当前主要问题：组合语义的作用域

以下两句仍会被生产分类器整句判为讨论，导致明确的选中指令丢失：

> 请选中蓝色球体，然后描述选中的物体。
>
> 请选中蓝色球体，然后解释选择结果。

原有八条本地分类断言可通过，两个近邻变体仍失败。根因是后置“描述/解释选择”被识别为评价语境后，前置命令未被正确保留；这类失败发生在视觉调用前。

处理方向是统一表示“执行选择”和“之后汇报”两个并存意图，保留否定、条件、引用与指代作用域。Jev 辅助判断仍是候选方案，尚未集成；见[方案](semantic-decision-plan.md)。
