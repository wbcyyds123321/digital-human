# 2026-11-11 阶段进展

> 这是公开源码快照的进展说明，不是完整 Unity 工程，也不是最终验收报告。仓库不包含角色模型、贴图、动画、地图 GLB/BLEND、音频、本机缓存、日志、Captures 或 API Key。

## 相比上一次公开快照

上一次公开快照已经有：LLM 对话、任务契约/Lua 执行、地图与导航、语音/视觉基础链路、程序化苏联地图生成工具。

本次增加/更新：

1. **第一人称通用物体选中**
   - 新增 `Assets/Scripts/Selection`：稳定实体 ID、实体目录/拾取注册表、RGB+ID+depth 同帧捕获、真实 Eye 转向、新帧中心确认、共享 Broker、高亮和坐标事实。
   - 新增 `FirstPersonTargetingService`：当前原图单图 → 模型 `point_uv/bbox_uv` → 同帧 ID/depth 绑定 → 实际转向 → 新帧确认 → 发布；不把实体 ID、候选框或世界坐标喂给模型。
   - 语义约束在视觉请求边界做保护：相对“X左边的Y”不会被误当成全画面 `leftmost`；否定、后置否定也不误激活绝对最左选择。
2. **DeepSeek 视觉链**
   - 产品视觉默认 provider=`DeepSeek`，模型=`deepseek-flash`，官方端点，空 fallback；单张原图输入，保留原始响应和诊断。
3. **白色选中实验室**
   - 新增独立 `WhiteboxSelectionLab` 场景与 Editor builder、7 个显式实体、屏风遮挡、观察点 A/B、准星/高亮/坐标/小地图。
   - 已跑通：红方块、右绿块、代词实时关系、被遮挡橙球 `not_found`、第二视点蓝球、蓝球左侧黄色圆柱；相对左语义经修复后通过。
4. **第一人称交互与动态世界**
   - 新增/更新 `Stage4`（座椅几何/坐下）、`Stage5`（视觉座椅选择）、`Dynamic`（车辆/电车/圣火/动态实体）、`WorldMap`（大地图数据与导航 provider）等运行时模块。
   - 最新这一轮没有重跑完整驾驶、座椅、上下车和复杂地图识别回归；README 不把“有代码链路”说成“全量验收”。
5. **语音稳定性**
   - 修复 `TaskSpeechQueue`/sidecar streaming 的 turn/service/token 隔离、取消、首音频确认、UI 输入时间栅栏、ASR 来源/捕获时间与去重。
   - 已验证注入 WAV barge-in/ASR、UI 打断旧播报、最终正文 TTS 的受控链路；**真人麦克风、口音、噪声、回声/主观听感仍 pending**。

## 验证边界（必须保留）

- 白盒 A/B 的目标是“当前画面视觉选中/瞄准/确认”，不是通用识别准确率或复杂苏联地图全场景泛化。
- 车/椅样本验证过选中、确认、坐标和部分高亮记录；最新白盒轮不重跑驾驶/坐下/上车完整链路。
- 独立外观图审曾因外部服务 HTTP403 被阻塞，不能声称独立图像外观验收。
- 真实人声与扬声器声学未验收。
- 仓库不包含可直接运行的完整 Unity 工程；使用需自行准备第三方包、角色/地图资产和 API 配置。

## 公开范围

- `unity/Assets/Scripts/`：运行时 C# 源码
- `unity/Assets/Editor/`：编辑器工具/场景构建与验证
- `voice/`：Python 语音 sidecar 脚本与说明
- `map/`：程序化地图生成和 Unity 运行时数据导出工具
- `docs/`：架构、roadmap 与展示截图

不包含：`Captures/`、`Logs/`、`.agent-bus/`、`Library/`、`Temp/`、模型/VRM/MMD/贴图/音频、地图 GLB/BLEND/渲染缓存、API Key/env 文件。
