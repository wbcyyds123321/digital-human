# 苏式蓝调小区 · Soviet Blue-Hour Microdistrict

> 一个可交互的 **苏联后朋克风微型小区（микрорайон）游戏地图**。
> 凌晨黎明前最深的蓝调时刻、浓雾、湿沥青、稀疏暖黄窗光；5 层赫鲁晓夫楼、9 层板楼、文化宫、
> 学校、锅炉房、公共浴场、市场、电影院、公园池塘，以及 **祖国母亲雕像、莫斯科大学主楼、
> 乌克兰饭店、外交部大楼、莫斯科地铁 pylon hall、布列斯特勇气浮雕墙、雅尔塔友谊疗养院、
> 苏联机器人研究院、交通部大楼、飞碟式/六边形车站、中苏学堂、军事博物馆**。
> 所有地标采用 **独立摄影棚建模 → 多角度 QA → 再放入地图** 的流程，材质按真实照片定制。

- **地块**：400 × 300 m（Blender Z-up，+Y = 北，1 unit = 1 m；共 48 栋建筑，34 种类型）
- **建筑**：住宅 16 栋 / 公共文化 13 栋 / 工业 6 栋 / **地标 13 栋**
- **场景**：38,454 对象、1,421,322 三角面（导出前按建筑合并）
- **材质体系**（Round 4）：
  - 赫鲁晓夫楼/院落：GREP 风化材质（灰泥裂纹/污渍/锈痕/苔藓，强做旧）
  - 地标/高楼/公共建筑：**24 张专属 GPT-Image 材质**（石灰岩/大理石/花岗岩/赭石抹灰/白混凝土/
    铜屋顶/蓝金马赛克/青铜/金饰/玻璃…）+ 13 张立面细节参考，仅极轻做旧——更干净、更接近照片
- **参考图**：GPT-Image（`gpt-image-2.5-flare`）共 **104 张**（小地图 + 26 套建筑三视图 +
  窗户/海报/材质 + 13 张地标三视图 + 8 张风化贴图 + **24 张地标专属材质 + 13 张地标细节图**），
  另加 **52 张真实苏联/俄式建筑照片**
- **交互**：three.js 第一人称步行（WASD + 鼠标 + 跳跃 + 碰撞 + 小地图 + 可登纪念台阶）＋ 导航图/碰撞体 ＋ Unity 导入说明

## 1.6 Round 4（本轮：地标质量重做）

用户审阅参考图后指出：部分地标"看不出是什么"、高楼不如照片、贴图一套用到底。本轮整改：

1. **独立摄影棚工作流**：新增 `tools/lm_studio.py` —— 每座地标先在独立场景高精度建模，
   自动渲 4 个转盘角度 + 正立面 + 背立面 + 近景细节（1100×800），对照 `ref/F` 三视图、
   `ref/H` 细节图与 `ref/web2` 真实照片反复迭代，**满意后才放进地图**。
2. **雕像重做**：祖国母亲重新建模——喇叭形长裙与褶皱、腰身、躯干、小头 + 发髻、举剑的手臂、
   前伸的左手、后扬斗篷、胸前金星、花岗岩基座；34→40 m，配 3 盏泛光灯。
3. **高楼重做**：莫大主楼（花岗岩基座 + 三层塔身 + 八角塔冠 + 铜脊塔尖 + 3.45 m 红星 + 钟塔 +
   柱廊）、乌克兰饭店（赭石抹灰 + 奶油色线脚 + 四角塔楼）、外交部（冷灰花岗岩竖肋 + 密集窗格 + 纹章）。
4. **现代主义重做**：飞碟车站（17 m 车削碟盘 + 环形玻璃 + 肋状底面 + 6 条外张腿 + 售票圆厅）、
   六边形车站（四层收缩六边壳 + 马赛克饰带）、友谊疗养院（152° 弧形双层拱廊 + 24 拱 +
   三排马赛克饰带）、机器人研究院（折叠板基座 + 抛物面壳体 + 机器人臂）、交通部（花岗岩竖肋 +
   交通主题浮雕 + 金色题字）。
5. **专属材质**：ref/H 24 张 GPT-Image 材质按真实照片配色生成（石灰岩、白大理石、灰/深花岗岩、
   赭石抹灰、奶油抹灰、白/灰混凝土、铜屋顶、蓝金马赛克、青铜、金饰、净玻璃、陶瓷砖、金属肋…），
   地标不再复用小赫鲁晓夫的脏贴图；风化只保留极轻的雨痕/污渍作点缀。
6. 新增 10+ 个地标机位（`CAM_LM_*`），可分别查看每座地标。
